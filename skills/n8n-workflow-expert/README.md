# n8n Workflow Expert

Comprehensive integrated skill for building production-ready n8n workflows using the n8n-mcp MCP server.

## What's Included

This skill integrates all 7 original n8n skills into one comprehensive guide:

1. **Expression Syntax** - Writing {{}} expressions and accessing variables
2. **MCP Tools** - Using n8n-mcp server tools effectively
3. **Workflow Patterns** - 5 proven architectural patterns
4. **Validation** - Interpreting and fixing validation errors
5. **Node Configuration** - Operation-aware node setup
6. **JavaScript Code** - Code node best practices
7. **Python Code** - Python code node guidance

## Use Cases

- Building new n8n workflows from scratch
- Troubleshooting existing workflows
- Writing expressions and Code nodes
- Validating workflow configurations
- Understanding n8n-mcp tool usage

## Quick Start

This skill activates automatically when working with n8n workflows. It provides:

- Expression syntax guidance ({{}} patterns)
- MCP tool selection workflows
- Common error fixes
- Production-tested code patterns
- Validation strategies
